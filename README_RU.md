# Lumen

**Lumen** — лаунчер приложений и трекер их использования для Linux, написанный на C++.

Цель Lumen — создать быстрый и настраиваемый лаунчер с возможностью отслеживания использования приложений, статистики сессий и современного графического интерфейса.

> 🚧 **Ранняя стадия разработки** — в данный момент Lumen представляет собой CLI-прототип. Графический интерфейс и отслеживание использования запланированы для будущих версий.

# Сборка

В данный момент Lumen находится на ранней стадии разработки.

Клонирование репозитория:

```bash
git clone https://github.com/YOUR_USERNAME/lumen.git
cd lumen
```

Компиляция и сборка текущего прототипа:

```bash
./install.sh
```

Вывести найденные приложения:

```bash
lumen --list
```

Открыть приложение:

```bash
lumen --open kitty
```

Выполнить поиск:

```bash
lumen --search firefox
```

Запуск графической оболочки:

```bash
    lumen
```

# Почему Lumen?

Lumen начинался как небольшой C++-проект для изучения Linux internals, управления приложениями и интеграции с рабочим столом.

В дальнейшем проект должен вырасти из простого лаунчера в полноценную панель активности рабочего стола.

Основной принцип проекта — **обучение через создание реального проекта**:

* API файловой системы Linux
* Управление процессами
* Спецификация `.desktop`
* Межпроцессное взаимодействие (IPC)
* Базы

## Установка обновлённой версии

Для Arch Linux запустите из корня проекта:

```bash
chmod +x install.sh
./install.sh
```

Установщик поставит зависимости, соберёт проект и установит исполняемый файл в `~/.local/bin/lumen`.

Данные трекера находятся в `~/.local/share/lumen/proc.json` и `~/.local/share/lumen/stat.json`. Пользовательский CSS находится в `~/.config/lumen/style.css`.

Файл настройки Lua для Hyprland устанавливается в `~/.config/hypr/lua/lumen.lua`. Если в системе используется `~/.config/hypr/hyprland.lua`, установщик добавит загрузку этого файла. В другом Lua entry point добавьте после инициализации `hl`:

```lua
dofile(os.getenv("HOME") .. "/.config/hypr/lua/lumen.lua")
```

Менеджер процессов запускается при событии `hyprland.start` командой `lumen --processmanager`. Для списка приложений используется один элемент на отображаемое имя; одинаковые имена из пользовательских и системных `.desktop` файлов не дублируются.
